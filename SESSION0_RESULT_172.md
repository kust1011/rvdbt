The checker uses exact rational IEEE decoding and integer bit predicates, with no host cast or DUT golden. FP→integer rounds before clipping, maps NaNs/infinities to the specified signed/unsigned endpoints, raises NV without NX for invalid results, and NX for valid inexact conversion. Integer→FP rounds the exact signed/unsigned integer once. FP→FP preserves signed zeros/infinities, canonicalizes NaNs and raises NV only for sNaN. ROD truncates then jams an inexact significand low bit, including overflow saturation. Tininess is evaluated after unbounded-exponent precision rounding, independently of final normal/subnormal encoding. Only active lanes accrue flags, ORed into initial sticky flags; conversion never newly raises DZ. Pinned Spike/pk and Sail0.14.1 plus the independent predicate check the observer packets. Only deterministic active values/flags are reference-compared; inactive agnostic values use an old-or-all-ones set, never unconditional reference byte equality. [Predicate/generator](scripts/rvv/directed/fpconvert172.py) and [semantic review](docs/rvv-validation/directed-task172/SEMANTIC_REVIEW.md) document the rules and reused machinery.
