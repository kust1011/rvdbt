The new asset is **staged, not uploaded**. The prepared upload command requires
an authenticated GitHub CLI; `gh` is not installed in this local workspace.
This is a publication dependency, not an offline reader dependency. Main must publish it and the reviewed
repository revision containing Task139 after merging 135–139. The existing
validation release tag targets historical 49c44174; adding assets does not update
its source ZIP. Until publication, current raw cannot be acquired solely from
public downloads. The staged asset and explicit-root reader remove the author

workflow.

merger/TestFloat, compiler/linker, Sail/QEMU/Spike, adapters and executable/library
build dependencies recorded in the individual package guides/logs. Excluded
binaries/work/cache are not an offline inspection dependency. The original live
collector remains author-path dependent. No promise of universal historical
oracle regeneration, byte-identical rebuilding, native target admission or guest
restart verification is added. Existing scoped MAC failures, two ACT original
reference blockers and all other exclusions remain.
