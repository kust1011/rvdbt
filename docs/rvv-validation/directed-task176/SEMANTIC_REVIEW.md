## Exact sqrt arithmetic

No host floating point or host sqrt is used for a golden. Given exact positive rational x, find floor(log2(x)), choose the output exponent by floor(exponent/2), and scale x by the square of the destination precision quantum. Integer isqrt gives q; exact rational comparisons assert q*q <= scaled_x < (q+1)*(q+1). Exactness determines NX. Comparing4*numerator against(2*q+1)^2*denominator determines which side of the output midpoint contains sqrt(x). RNE uses even parity, RMM uses the upper endpoint on a tie; RTZ/RDN choose the lower endpoint and RUP chooses the upper endpoint when inexact. Carry normalization is explicit. A positive finite FP32/64 input has a normal finite sqrt, so UF/OF are impossible. Zero sign is preserved; negative nonzero and negative infinity produce canonicalNaN+NV; signaling NaN accruesNV. Rational exact-square and midpoint-square inputs are generated with directed rational rounding, not host sqrt.
