The full audit consumes the persistent frozen corpus in place. It regenerates the exact finite manifest and global ordinals, requires one result for every declared case in each Reference/B/M1/M2/BOTH arm, checks command return codes/timeouts and complete output extent, and verifies every build receipt, logical/compressed artifact identity, target instruction word and generated source. Nonzero-start Sail machine adapters are checked against the shared original user body and data; adapter setup/terminal I/O do not replace the target.

Every packet is checked against the unchanged ISA predicate: exact initial bytes; all 32 vector registers; vl/vtype/vlenb/vstart/vxrm/vxsat/vcsr/fflags/frm/fcsr plus s0 before/after; raw fs0 before/after; active fused results; accrued active-only flags; legal prestart/inactive/tail/no-body behavior; old/all-ones agnostic allowed sets. Every DUT active result/fflags is separately compared with independently executed pinned Spike (zero start) or Sail0.14.1 (nonzero start). There is no NaN-result or flag exclusion.

The Task160 partitioner assigns disjoint whole units to four subprocesses running this snapshot's auditor. It checks the original whole denominator before partition, disjoint merged rows and counts, shard adapter/pin uniqueness and original input hashes before/after. Its retaining extension adds an explicit failure branch after complete merging; predicate failures remain FAIL, produce return1 and ALL_ACCOUNTED_WITH_FAILURES, and never become PASS or COMPLETE. The four traversal worker return codes can therefore be zero while the parent returns semantic failure. Traversal completion, strict semantic outcome, controls/export success and runner execution outcome are separate receipts.

Original runner result rows stop at the first ISA mismatch and may leave `reference_status=BLOCKED` for the failed DUT packet. The reference guest has still executed and passed in that unit. Supplemental findings read each failed original DUT/reference pair and reject it through the independent-reference predicate, retaining original fields and exact offsets/hashes. They characterize results versus flags rather than rewriting the runner's history.

Controls are bounded actual-packet replay, with no guest command: both ends of active results; every CSR/s0; fs0 pre/post; captured source and old destination; other registers; required preservation; and effective allowed agnostic bytes. Fused witnesses replace result/flags/fcsr with a separately rounded product then sum and require rejection by both predicates. Distinct physical inputs similarly replace results with swapped destructive roles and wrong product/addend signs. Full selection covers every form/geometry and all five modes through the small-geometry supplement. All original predicates remain frozen.

This establishes finite execution/checking denominators and retains a reproduced legal exception defect. It is not a full semantics proof, an original-QEMU-suite PASS, or per-PC proof that M1/M2 admitted any target. The independent FMA checker review and main acceptance remain pending. RMM passing in the diagnosed witness bins does not establish a route or root cause in the pinned binary. No production file is modified, no prior accepted matrix reruns, and no Linux/LLVM/performance or forbidden handler/retry expansion occurs.
