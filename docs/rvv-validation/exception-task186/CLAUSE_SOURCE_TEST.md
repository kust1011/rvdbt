## Cost accounting

Task186 adds **zero production translation metadata, zero emitted normal-path
instructions, and zero cold-recovery instructions**. All production source
bytes remain at the base revision. No throughput or performance matrix was run.
This zero delta does not mean the existing exception machinery is free:

- Translation/publication allocates and registers exact native memory-site
  metadata and emits cold labels; this costs translation time/code space.
- Normal memory frames already have a call/spill boundary, live admission call
  and branch, runtime geometry guards and architectural load publication.
  Scalar vector-memory loops already store vstart per active element. These
  are existing memory costs, not new per-arithmetic-instruction checkpoints.
- On a fault only, the signal callback scans exact-site metadata, captures TLS
  fields and redirects to cold code; cold code queues the event, closes FP
  state and unwinds. Dispatcher snapshot copying is also cold work.

No general scalarization, Linux scalar/atomic expansion or LLVM route change
was made or validated here.
